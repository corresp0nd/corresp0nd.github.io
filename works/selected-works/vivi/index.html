Vivi

Vivi is a 3D character model based on the video game Space Channel 5.

fall 2025

About

This project was to create a character model based on an older game in both the style and roughly similar technical limitations. Vivi is a study on Space Channel 5: Part 2. She's roughly 6,000 tris with some very basic rigging, as the project was mostly just about topology rather than posing. Rather than a news reporter like Ulala, Vivi is a cosmic storm chaser who also reports the local weather.
